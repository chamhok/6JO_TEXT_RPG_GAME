# 흑섬: 닌자의 궤적

마우스로 공격 경로를 그린 뒤 버튼을 놓으면 닌자가 그 궤적을 초고속으로 질주하며 적 대군을 베는 2D 닌자 핵앤슬래시 웹게임입니다.

## 현재 빌드

- v0.4.0
- 무한 웨이브 생존전
- 8단계 전투 튜토리얼
- 무한 자원 자유 연습장
- 발도참, 연쇄참, 월영참, 그림자 봉인, 인술 폭발, 반격

게임은 저장소의 `index.html`에 모든 코드와 스프라이트가 포함된 단일 파일로 배포됩니다.

## 조작

- 빠른 마우스 드래그: 즉응 참격
- 0.10초 이상 누른 뒤 드래그: 집중 참격
- T: 튜토리얼
- P: 자유 연습장
- Space: 긴급 회피
- R: 훈련 표적 재배치
- B: 제목 화면

캐릭터 스프라이트는 Ninja Adventure Asset Pack의 CC0 에셋을 사용합니다.
